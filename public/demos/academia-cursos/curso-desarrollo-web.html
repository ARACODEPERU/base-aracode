Desarrollo Web Full Stack

Del HTML a una aplicación con base de datos y usuarios. Sales con tres proyectos publicados y un portafolio que puedes mostrar en una entrevista.

Duración
24 semanas
Carga
288 horas
Horario
Lun · Mié · Vie, 19:00 a 22:00
Inicio
Lunes 2 de noviembre

Qué vas a aprender

Seis módulos, en este orden. Cada uno cierra con un ejercicio entregable, así que llegas al proyecto final con todo practicado.

01 · Base de la web: HTML y CSS

Estructura de una página, etiquetas semánticas, formularios y maquetación con flexbox y grid. Terminas con una página publicada.

  • Semana 1: cómo se arma una página y qué es el navegador
  • Semana 2: etiquetas semánticas, textos, imágenes y enlaces
  • Semana 3: formularios y validación del navegador
  • Semana 4: flexbox, grid y adaptación al celular
02 · Programar: JavaScript para el navegador

Variables, funciones, arreglos, objetos y eventos. Consumo de datos de una API y manipulación de la página con ejercicios reales.

  • Semana 5: variables, tipos y funciones
  • Semana 6: arreglos y objetos con datos de un catálogo
  • Semana 7: el DOM: leer y cambiar la página
  • Semana 8: eventos, formularios y validación propia
  • Semana 9: consumir una API y mostrar los datos
03 · Servidor: PHP y lógica del lado del servidor

Formularios que guardan datos, sesiones, validación y organización del proyecto por carpetas para no perderte en tu propio código.

  • Semana 10: qué pasa entre el navegador y el servidor
  • Semana 11: PHP: variables, condiciones y ciclos
  • Semana 12: recibir un formulario y validarlo
  • Semana 13: sesiones: recordar al usuario
  • Semana 14: organizar el proyecto: carpetas y reutilización
  • Semana 15: repaso y primer entregable integrador
04 · Datos: base de datos y SQL

Diseño de tablas, relaciones, consultas con filtros y reportes. Conectas la base de datos a la aplicación del módulo anterior.

  • Semana 16: tablas, tipos y claves
  • Semana 17: consultas: filtros, orden y agrupación
  • Semana 18: relaciones y consultas entre tablas
  • Semana 19: conectar la aplicación a la base de datos
05 · Publicar: puesta en producción

Dominio, hosting, certificado y respaldos. Los tres proyectos del curso se publican en línea durante esta etapa.

  • Semana 20: dominio, hosting y certificado
  • Semana 21: subir el proyecto y resolver el primer error real
  • Semana 22: respaldos, correo y correcciones
06 · Proyecto final y presentación

Desarrollas una aplicación para un caso real, la documentas y la presentas ante el grupo: es la última clase y la primera defensa de tu trabajo frente a otros.

  • Semana 23: alcance, bocetos y base de datos del proyecto
  • Semana 24: terminar, publicar y presentar

Para quién es este curso

  • Quien nunca programó y quiere empezar con acompañamiento
  • Quien ya toca plantillas web y quiere entender lo que pasa por dentro
  • Trabajadores de soporte o diseño que quieren pasar a desarrollo
  • Quien tiene una idea de negocio y quiere construirla

Qué necesitas traer

  • Laptop propia recomendable (hay equipos del laboratorio si no tienes)
  • Ganas de practicar entre clases: unas cinco horas por semana
  • Lectura y matemática básica: no se pide más

Cómo se evalúa

No hay un examen único que decida todo. La nota sale de los ejercicios de cada módulo, la entrega de los tres proyectos y la presentación final. Para el certificado se pide asistir al menos al 75% de las sesiones y aprobar el proyecto.

Preguntas sobre este curso

¿Puedo llevarlo si solo tengo una laptop prestada?

Sí. Puedes usar el laboratorio para practicar en las horas libres; avísanos al matricularte para reservarte una máquina.

¿Se puede llevar en el turno de mañana?

Este curso se dicta solo en el turno noche. Si trabajas de noche, hay turnos de mañana en los cursos de gestión y diseño.

¿Qué pasa si me atraso en un módulo?

Al inicio de cada clase repasamos el ejercicio anterior y el docente te alcanza el material del módulo. Las grabaciones quedan una semana.
